# 프리니 1·2 비공식 한국어 패치 v1.1

프리니 1 `ULJS00150`과 프리니 2 `NPJH50211`의 최종 한국어 패치입니다.

게임 ISO는 포함하지 않습니다. 정품에서 직접 추출한 무수정 일본판 ISO에 xdelta3 패치를 적용해야 합니다.

## 다운로드

- [프리니 1 한국어 패치 v1.1](https://github.com/sizz1214-lang/prinnyk/releases/tag/v1.0)
- [프리니 2 한국어 패치 v1.1](https://github.com/sizz1214-lang/prinnyk/releases/tag/prinny2-v1.0)

기존 다운로드 주소와의 호환을 위해 릴리스 태그와 파일명은 유지하고, 파일 내용과 릴리스 표기는 v1.1 최종본으로 교체했습니다.

## v1.1 최종 수정

- 프리니 1: 건너뛰기 문구를 갈무리 글꼴로 정리하고 클리어 리포트 트로피 위치를 보정
- 프리니 2: 조건 달성 알림·아이템 명칭 등 남은 일본어를 한국어로 수정
- 프리니 2: 건너뛰기 문구와 클리어 랭크 위치·표현을 최종 보정
- 프리니 2: 게임 아이콘과 배경 이미지를 최종 한국어판 리소스로 교체
- 두 게임 모두 최종 ISO 콜드 부팅 및 화면 확인 완료

## 지원 환경

- PSP CFW ISO 로더
- PS Vita 6.61 Adrenaline
- PPSSPP

PS Vita에서 `80020148`이 발생하면 Adrenaline Recovery Menu의 `Execute BOOT.BIN in UMD/ISO`를 활성화하십시오.

원본 ISO의 크기와 SHA-256을 확인한 뒤 패치를 적용하십시오. 다른 지역판이나 리비전에는 적용하지 마십시오.
