# 디스가이아 인피니트 비공식 한국어 패치 V1.0

PSP 일본판 `디스가이아 인피니트`(`ULJS00286`)용 한국어 패치입니다.
게임 ISO는 포함하지 않습니다. 정품에서 직접 추출한 무수정 일본판 ISO에
`xdelta3`로 패치를 적용하십시오.

## 대상 파일

| 구분 | 크기 | SHA-256 |
|---|---:|---|
| 무수정 일본판 ISO | 220,889,088 bytes | `32de3247bed3c78fdb66a9fe6d6a973ac808982d2472f569a90809135df9cce5` |
| 패치 결과 ISO | 220,889,088 bytes | `234e9f3bfac930e88cabf779ccc33abe343b4061896634b960c3d3b8deb07f86` |

원본 해시가 다르면 적용하지 마십시오. 다른 지역판·수정본·압축 이미지에는
호환되지 않습니다.

## 간편 적용

- Windows: 원본 ISO를 `apply_patch_windows.bat` 위로 끌어다 놓습니다.
- Linux/macOS: `sh apply_patch_linux_macos.sh "원본.iso"`를 실행합니다.

`xdelta3`가 설치되어 있어야 합니다. 정상 적용 결과는 같은 폴더의
`Disgaea_Infinite_ULJS00286_KR_v1.0.iso`입니다.

## 직접 적용

```bash
xdelta3 -d -s "Disgaea Infinite (Japan).iso" \
  "Disgaea_Infinite_ULJS00286_KR_v1.0.xdelta" \
  "Disgaea_Infinite_ULJS00286_KR_v1.0.iso"
```

## 주요 내용

- 대사, 메뉴, 도감, 튜토리얼, 시스템 문구 한국어화
- 한국어 글꼴과 게임 내부 텍스처·ANM 그래픽 통합
- 시작 선택창 글자 축소 및 패널 확대
- 자동저장 안내 문구와 누락 글리프 수정
- PSP XMB 제목·아이콘·배경 한국어화
- 외부 텍스처팩 없이 ISO 단독 실행

## 실행 설정

- PPSSPP에서 메모리스틱 삽입을 켜십시오.
- 외부 텍스처 교체는 필요하지 않으며 끄는 것을 권장합니다.
- 문제 확인 시 먼저 위의 원본/결과 SHA-256을 비교하십시오.

## 검증

- xdelta 디코드 결과와 최종 ISO `cmp` 완전 일치
- 정적·아카이브·ISO 재추출 QA 61/61 PASS
- PPSSPP 1.20.4에서 최종 ISO의 자동저장 안내 및 시작 선택 화면 부팅 확인
- 전체 게임 완주 검수는 수행하지 않았습니다.

자세한 증거는 `docs/`의 manifest, 정적 QA 보고서와 런타임 캡처를 참조하십시오.

## 주의

본 패치는 비공식 팬 번역입니다. 게임 ISO와 원본 데이터 파일은 배포하지 않습니다.
정품을 소유한 사용자가 개인적으로 패치를 적용하는 용도로만 사용하십시오.
