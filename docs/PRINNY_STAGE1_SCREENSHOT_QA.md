# 프리니 1 스테이지 화면 QA 메모

이 문서는 사용자가 제공한 스테이지 1 시험 화면 18장을 기준으로 만든 **시각 검수 목록**이다. 문자열 ID/오프셋은 아직 화면만으로 확정하지 않았으므로, 자동 문자열 카탈로그의 `resource + offset`과 연결하기 전에는 게임 파일을 직접 수정하지 않는다.

## 확인된 문제 유형

1. **일본어 UI 잔존**
   - 난이도 설명, 튜토리얼 팝업, 일시정지 메뉴, 스테이지 결과, 튜토리얼 목록과 도움말이 일본어로 남아 있다.
   - 현재 번역 마스터에 포함된 START 자원 외에 SCRIPT.DAT, UI 문자열 또는 이미지 리소스까지 조사해야 한다.

2. **깨진 글리프/잘못된 코드 배정**
   - 검은 사각형, `M`, `O`, `H`, `L`, `d`, 한자 조각 등이 한국어 문장 안에 섞인다.
   - 단순 번역 누락뿐 아니라 문자 배정표 불일치, 원문 제어 바이트 오인식, 문자열 경계 오탐 가능성이 있다.

3. **문장 일부 소실·혼합**
   - 문장 앞뒤가 잘리거나 일본어 조각이 붙고, 조사·음절이 사라진 장면이 있다.
   - 고정 슬롯 용량, 원문 접두 바이트, 인접 데이터 경계와 포인터형 문자열 여부를 다시 확인한다.

4. **과도한 자간과 줄바꿈**
   - 대화창에서 한글 음절 사이가 넓게 벌어지거나 문장이 비정상적으로 분산된다.
   - 현재 20×14 고정폭 추정뿐 아니라 실제 대화창별 최대 글자 수와 줄바꿈 규칙이 필요하다.

## 자동화에 반영한 사항

- 번역 마스터의 바이트 초과, 일본어 잔존, 미등록 문자, 제어 토큰 불일치 검사
- 화면 폭과 명시적 줄 수의 보수적 경고
- 기존 번역 occurrence에 포함되지 않은 일본어 문자열 후보 추출
- 프리니 1/2의 SYSTEM.DAT, START, 폰트, SCRIPT.DAT 구조 비교
- 원본 ISO를 덮어쓰지 않는 별도 빌드·보고서 생성

## 남은 수동 작업

사용자는 `workspace/reports/prinny_qa/review_queue.csv`의 번역문과 실제 게임 화면만 검수하면 된다. 파일 분석, 후보 추출, 코드 수정과 보고서 생성은 통합 명령에서 처리한다.
