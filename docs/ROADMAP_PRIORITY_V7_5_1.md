# Roadmap priority V7.5.1

## 1순위 — 프리니 1

현재 18개 오류를 다음 순서로 처리한다.

1. 스크린샷 현상과 실제 START/BOOT/EBOOT 자원 연결
2. 오프셋, 원본 바이트, 제어코드, 슬롯 한도 확정
3. 번역 문구와 캐릭터 말투를 잠근 채 구조 결함만 수정
4. Expected Write, 실제 변경 수, 재압축 결과 검증
5. 별도 ISO 생성 및 PPSSPP 사용자 검수

새 빌드는 실제 변경이 0개이거나 Expected Write가 불일치하면 실패로 처리한다.

## 2순위 — 프리니 2

기존 결과를 유지한다.

- 번역 후보 4,286개
- 첫 번역 묶음 200개
- 문맥 및 안전 슬롯 200/200 연결
- 고우선 폰트 후보 2개

프리니 1 핵심 이정표 전에는 신규 번역 묶음을 만들지 않는다.

## 3순위 — PSP 한글화 통합툴

프리니 1의 증거 연결, 패치 검증, PPSSPP 테스트에 필요한 기능만 구현한다.
일반 기능 확장과 외형 개선은 프리니 1 수정 이후로 미룬다.

## 번역 보호

프리니 1 캐릭터 말투, 어미, 감탄사, 반복, 말줄임표는 자동 수정하지 않는다.
