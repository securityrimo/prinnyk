# 번역 보존 정책

이 프로젝트의 번역문은 캐릭터별 말투를 의도적으로 반영한 역자 자산이다.

## 자동 적용 가능

- 슬롯 용량 초과를 해소하는 최소 수정
- 번역문에 남은 명백한 일본어·한자 제거
- 제어코드, 종료 바이트, 포인터, 인코딩, 글리프 매핑 오류 복구

## 역자 승인 전 자동 적용 금지

- `슴다`, `임다` 등 캐릭터 고유 어미 수정
- 감탄사, 장음, 반복, 말줄임표 변경
- 문장 축약, 순화, 자연스러운 표현으로 재작성
- 띄어쓰기나 문맥 제안이라도 원문과 화면 용량을 확인하지 않은 변경

제안 사항은 `stage1_review_only.csv`로만 내보낸다.
